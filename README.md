# 🤖 Missão IA: Você Decide o Futuro da IA

Uma história interativa desenvolvida na web onde as escolhas do usuário moldam uma narrativa sobre o impacto, ética e uso da Inteligência Artificial no cotidiano e no futuro da sociedade.

---

## 📋 Sobre o Projeto

O projeto **Você Decide o Futuro da IA** é uma aplicação web interativa desenvolvida durante as aulas de programação e tecnologia da **FIAP / Alura**. 

O objetivo é apresentar dilemas reais sobre a Inteligência Artificial — como seu uso em trabalhos escolares, o impacto no mercado de trabalho e a criação de conteúdos autoriais versus gerados por máquina. Conforme o usuário responde às perguntas, suas escolhas são armazenadas e uma história personalizada referente ao ano de 2049 é gerada ao final.

---

## 🎯 Funcionalidades

- **Navegação Dinâmica:** As perguntas e alternativas mudam em tempo real via manipulação do DOM no JavaScript.
- **Construção de Narrativa:** Cada opção escolhida acumula uma afirmação que compõe um resultado final exclusivo.
- **Design Responsivo:** Interface minimalista, adaptada para telas de dispositivos móveis e desktops.
- **Interatividade Visual:** Feedback nos botões com efeitos de *hover* e transições suaves em CSS.

---

## 🛠️ Tecnologias Utilizadas

O projeto foi construído utilizando as tecnologias fundamentais da Web:

- **HTML5:** Estruturação semântica e caixas organizadoras da aplicação.
- **CSS3:** Estilização moderna utilizando Variáveis CSS (`:root`), Flexbox para centralização e efeitos de transição.
- **JavaScript (ES6+):** Lógica do jogo, controle de estado, arrays de objetos e eventos do DOM.
